# NOVA դպրոց → Netlify

Սա Netlify-ի համար պատրաստված ամբողջական Next.js նախագիծն է՝ էլ․ հասցեով և գաղտնաբառով մուտքով, ուսուցիչների ու ծնողների բաժիններով, մատյանով և օրագրով։ Տվյալները պահվում են առանձին Turso տվյալների բազայում։

Այս ZIP-ը սովորական HTML կայք չէ։ Netlify Drop-ի մեջ գցելը բավարար չէ․ անհրաժեշտ է GitHub-ից build անել, որպեսզի աշխատեն մուտքն ու սերվերային API-ները։ Netlify-ի իրական հրապարակում դեռ չի կատարվել։

## 1. Բացել հաշիվները

- Netlify՝ https://app.netlify.com/
- Turso՝ https://turso.tech/
- GitHub՝ https://github.com/

Turso-ն առաջարկում է անվճար մեկնարկային պլան՝ սահմանաչափերով։ Հետևիր նաև քո Netlify պլանի սահմանաչափերին։

## 2. Պատրաստել տվյալների բազան

Turso-ում ստեղծիր դատարկ բազա՝ `nova-school` անունով։ Պահիր դրա Database URL-ը և Auth Token-ը։ Token-ը տվյալների բազայի գաղտնի մուտքի բանալին է։

## 3. GitHub և Netlify

1. Բացիր ZIP-ը։
2. GitHub-ում ստեղծիր նոր դատարկ repository, օրինակ՝ `nova-school`։
3. Upload files-ով ներբեռնիր այս թղթապանակի ամբողջ պարունակությունը։ `package.json`-ը և `netlify.toml`-ը պետք է լինեն repository-ի արմատում։ `node_modules` և `.next` թղթապանակները պետք չեն։
4. Netlify-ում ընտրիր Add new project → Import an existing project → GitHub և ընտրիր repository-ն։ Կոճակների անունները կարող են տարբերվել միջերեսի լեզվից։
5. Build command՝ `npm run db:migrate && npm run build`
6. Publish directory՝ `.next`
7. Node.js՝ 22։

## 4. Netlify Environment variables

Մինչև հաջող build-ը ավելացրու այս արժեքները՝ Build և Functions միջավայրերում հասանելի լինելու համար․

| Անուն | Արժեք |
|---|---|
| `TURSO_DATABASE_URL` | Turso-ի Database URL-ը |
| `TURSO_AUTH_TOKEN` | Turso-ի Auth Token-ը՝ գաղտնի արժեք |
| `ADMIN_EMAIL` | Քո ադմինի իրական էլ․ հասցեն |
| `ADMIN_NAME` | Ադմինի անունը և ազգանունը |
| `ADMIN_SETUP_TOKEN` | Նոր, պատահական, առնվազն 32 նիշանոց մեկանգամյա կարգավորման բանալի |
| `NOVA_MAIL_SCRIPT_URL` | Քո Google Script-ի `/exec` հասցեն |
| `NOVA_MAIL_SCRIPT_SECRET` | Google Script-ի `NOVA_SECRET` հատկության նույն արժեքը՝ գաղտնի |

Գաղտնի արժեքները կոդի կամ GitHub-ի մեջ մի ավելացրու։ ZIP-ում իրական գաղտնի բանալիներ և գործող կայքի տվյալներ չկան։

## 5. Առաջին գործարկում

Deploy-ից հետո բացիր քո նոր Netlify հասցեն՝ `/setup-admin` վերջավորությամբ։ Գրիր ADMIN_EMAIL-ը, ADMIN_SETUP_TOKEN-ը և ստեղծիր քո մուտքի գաղտնաբառը։ Հետագա բոլոր մուտքերը կլինեն `/login` էջով՝ էլ․ հասցե և գաղտնաբառ։ ChatGPT մուտք պետք չէ։

Ադմինի հաշիվը ստեղծվելուց հետո նույն կարգավորման էջը կրկին ադմին չի ստեղծում։ ADMIN_SETUP_TOKEN-ը կարող ես հեռացնել միջավայրից և redeploy անել։ Հաջորդ build-երի համար migrate script-ը պահանջում է այդ բանալին միայն երբ ադմինի հաշիվը դեռ չի ստեղծվել։

## 6. Հին տվյալների տեղափոխում

Հին կայքը շարունակում է առանձին աշխատել։ Տեղափոխումը դեռ չի կատարվել։

Հին կայքում՝ Կառավարում → Ներբեռնել տվյալները, ստացիր NOVA JSON պատճենը։ Այն պարունակում է դասարանները, աշակերտներին, առարկաները, դասացուցակը, գնահատականները և հաստատված ծնող–երեխա կապերը։ Այն չի պարունակում օգտատերերի գաղտնաբառերի հաշված արժեքները կամ սպասող ծնողների հայտերը։

Ներմուծելու համար նոր բազան պետք է դատարկ լինի, և նոր ադմինի գաղտնաբառը դեռ չպետք է սահմանած լինես։ Համակարգչիդ վրա՝

1. Տեղադրիր Node.js 22 կամ ավելի նոր։
2. Այս թղթապանակում գործարկիր `npm ci`։
3. `.env.example`-ը պատճենիր `.env.local` անունով և լրացրու բազայի միացման տվյալներն ու ADMIN_EMAIL-ը։ Այդ ֆայլը GitHub մի ուղարկիր։
4. Գործարկիր՝ `node --env-file=.env.local scripts/import-school.mjs PATH-TO-NOVA-BACKUP.json`՝ վերջին մասում գրելով քո JSON ֆայլի ուղին։
5. Հետո նոր կայքում սահմանիր ադմինի գաղտնաբառը։
6. Ուսուցիչների և արդեն հաստատված ծնողների համար սահմանիր նոր գաղտնաբառեր։ Սպասող ծնողները նոր կայքում կրկին գրանցվում են։

Ներմուծումը հրաժարվում է վերագրել արդեն օգտագործվող բազան։ Մինչև վերջնական անցումը նոր կայքում ստուգիր դասարանները, երեխաների կապերը, գնահատականներն ու նամակների ստացումը։

## Ստուգումներ

- `npm test`՝ SQL adapter, մուտքի, դերերի և ծնողի հաստատման ստուգումներ։
- `npx tsc --noEmit`՝ TypeScript։
- `npm run build`՝ Next.js production build։

Այս պատրաստման ժամանակ ստուգումներն ու build-ը հաջող են ավարտվել։ Իրական Turso բազային միացումը և Netlify-ի հրապարակումը սպասում են քո հաշիվների կարգավորմանը։
